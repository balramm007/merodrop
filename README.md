# MeroDrop 🚀
**Simple, Fast, Private P2P File Sharing**

MeroDrop is a professional web-based file-sharing application powered by Balram Pathak Official-Balram AI. It enables direct device-to-device transfers using WebRTC, ensuring your data never touches a server.

### ✨ Key Features
- **P2P Discovery:** Instantly find other devices on your local network.
- **Hybrid Controls:** Left-click/Tap for files, Right-click/Long-press for chat.
- **Smart UI:** Auto-scaling grid that supports up to 50 users.

### 🚀 Getting Started
1. `npm install`
2. `npm run dev`
